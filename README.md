# Outlier Detection Using Box Plot

## 📌 Project Overview
This project focuses on detecting potential outliers in a numerical dataset using a box plot and the Interquartile Range (IQR) method.

## 🎯 Objective
To understand outlier detection through data visualization and identify unusual values in the dataset.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📊 Dataset
An Employee Salary dataset is used for this project. It contains numerical salary values, including a high value to demonstrate outlier detection.

## 🔍 Methodology
1. Import the required Python libraries.
2. Create the employee salary dataset using Pandas.
3. Visualize the salary distribution using a box plot.
4. Calculate Q1, Q3, and the Interquartile Range (IQR).
5. Calculate the lower and upper limits.
6. Identify potential outliers using the IQR method.
7. Analyze the results.

## 📈 Visualization
A box plot is used to display the distribution of employee salaries and highlight potential outliers.

## ✅ Results
- Successfully created a box plot.
- Calculated the Interquartile Range (IQR).
- Identified potential outliers using the IQR method.
- Detected an unusually high salary value of 200000 in the sample dataset.

## 📝 Conclusion
Outlier detection helps identify unusual values in numerical data. The box plot and IQR method provide a simple way to detect potential outliers. However, outliers should be investigated before deciding whether to remove them.
